# Calulate

## Overview

A simple calculator for deterministically computing simple math operations. You
should ALWAYS use this tool to do math - NEVER guess.

## Supported Operations

- `ADD`: Sums the provided terms together. 1 + 2 = 3.
- `MULTIPLY`: Multiplies the terms together. 2 * 3 = 6.
- `POWER`: Takes the first term to the power of the second term. 2 ** 3 = 8.
- `SUBTRACT`: Takes the second term from the first term. -3 - 4 = -7.
- `DIVIDE`: Divides the terms in the order provided. 4 / 2 = 2.
- `MODULUS`: Returns the remainder from the first term when dividing the second
  term into it. 9 % 2 = 1.

## Best Practices

- Since you can only execute one operation at a time, remember your order of
  operations when planning.
- Avoid dividing by zero! This will throw an error.
